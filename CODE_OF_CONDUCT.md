# Code of conduct

Leaseweb Dock follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, keep discussions about the work, and do not harass anyone, in issues, pull requests or anywhere else the project lives.

If someone breaks these rules, report it privately to the maintainer through the [Security tab](https://github.com/MahdiGraph/LWDock/security) (**Report a vulnerability** works for conduct reports too). Reports are handled confidentially.
